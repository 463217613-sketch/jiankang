# 健康小助手

给父母用的家庭健康记录工具。单文件网页，双击就能用，不需要安装、不需要登录、不需要联网。

## 怎么用

直接打开 `index.html`（用浏览器）。也可以开启 GitHub Pages 后通过网址访问，手机上可「添加到主屏幕」，像 App 一样用。

## 有什么功能

- **今日**：记血压／血糖／体重／一句话，立刻给出判定；显示今天分时段该吃的药、该量的项目；一键生成发给家人的微信卡片。
- **趋势**：最近 14 次血压折线图与明细。
- **档案**：基础信息、用药与补品（含重复成分提示）、体检指标（带日期，便于逐年对比）、饮食喜好。
- **资料**：上传体检报告／化验单／CT／病历／药盒照片，自动归类；由 AI 分析后把结论回填进档案。
- **设置**：血压判定阈值、测量提醒、同步码、导出／导入、自动备份回滚。

## 数据在哪里

**所有数据只存在使用者的这台设备的浏览器里**（记录用 localStorage，资料文件用 IndexedDB），不会上传到任何服务器。

- 换手机／换人：用设置页的「同步码」搬运，或导出 JSON 再导入。
- 自动备份：每 6 小时存一份快照，保留最近 5 份，可一键回滚。
- 导出可加口令加密（PBKDF2 + AES-GCM），口令遗忘无法找回。

## 边界（重要）

- 本工具**不做诊断、不开处方、不替代医生**。任何异常只输出「去医院复查」一个结论。
- 用药冲突检查只标出**重复成分**，提示一律附「去问药师」的出口，不替医生拍板。
- 每日菜谱为内置库按日期轮换，会依忌口过滤（低钠、海鲜过敏、牙口不好等）。

## 技术说明

纯静态单文件，零外部依赖（无 CDN、无外链字体、无第三方脚本），离线可用。
