手机上怎么装成 App

这个页面已经在线上了，但要不要存数据得注意两件事：

1. 别在微信里直接存。微信内置浏览器会清缓存，记录可能丢。点右上角「···」→ 用 Safari / 系统浏览器打开，再添加到主屏幕。

2. 数据只在这台手机上。你手机和爸妈手机各存各的，看不到对方的。要同步就用下面的导出 / 导入。

添加到主屏幕后，图标和 App 一样，每天点开就是当天新菜谱。

血压判断标准

默认 140 / 90，按医嘱改。这个工具不诊断，超了只会提醒去复查。

测量提醒

同步到另一台手机

数据现在存在这台手机的浏览器里。想让爸妈手机上也有同一份，或换手机接着用，就生成一段同步码，微信发过去，那边粘进来。

按名字对上就更新，对不上就新增一份，不会直接删你的档案。

云端永久保存

数据只存在浏览器里，清缓存就会丢。开启后，每次记录自动存进你自己的 GitHub 私有仓库——永久保存、自带历史版本、换手机能拉回全部记录。

需要你先做两件事：① 建一个私有仓库（比如 jiankang-data）；② 生成一个访问密钥，权限只勾这个仓库的 Contents: Read and write。密钥只存在这台设备的浏览器里。

数据

所有数据只存在这台设备的浏览器里。换手机、换人、备份都靠导出。

忘了导出口令就解不开，没有后门。这是刻意的设计。

这个模板怎么用给下一个人

点顶部「加人」填一份新档案就行，模板本身不用改。父母是两份，以后给谁用都是再加一份。
